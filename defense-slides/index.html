07 · 核心贡献

瞬时温度响应只识别一个边界方向

表面热流

qs = [h + εhrad(Ts,T∞)](T∞−Ts)

对 h 与 ε 的瞬时灵敏度

∂qs/∂(h,ε) = (T∞−Ts)[1, hrad]
Jacobian 秩为 1
可观测组合 Heff = h + εhrad

结论限定在本文单步、均匀灰体、h(t) 与 ε(t) 逐时自由变化的观测模型下。

网络直接接收 Heff，可消除训练输入中的等价方向。

这是论文最有辨识度的部分。强调“局部、瞬时、本文观测模型”，不要说 h 和 ε 在所有情况下永远不可辨识。

辐射项随候选炉温改变，需要 h、ε 的后验成员。

Heff 是单步前向转移的充分输入，不是整个反事实控制问题的充分统计量。

这页回答评委可能追问的矛盾：既然不可分，控制时为什么还保留 h 和 ε。原因是新炉温会改变辐射基函数。

备用 01 · 概念定位

为什么称为“世界模型”

评委可能问：这与普通代理模型有什么区别？

本文所称世界模型，是一个以物理状态、控制输入和系统参数为条件，能够递归预测状态演化并支持反事实规划的可学习动力学模型。

物理状态直接使用温度场，无需图像潜空间
动作条件炉温是显式控制输入
递归调用完整 300 步闭环 rollout
规划用途控制器反复评价未执行动作

若模型只执行一次前向预测，它可以归入代理动力学模型；本文强调的是闭环中的功能角色。

回答保持简洁。不要用模型规模、生成能力或潜空间来论证世界模型。

备用 02 · 数学说明

h 与 ε 的局部不可辨识性从何而来

1

固定 Ts 与 T∞，表面热流可写为
qs = (h + εhrad)ΔT

2

灵敏度向量为
∂qs/∂(h,ε) = ΔT[1,hrad]

3

任取 δε，并令
δh = −hradδε，当前热流保持不变。

4

映射 (h,ε) → qs 非单射，瞬时 Jacobian 只有一个独立方向。

可恢复条件 若 h、ε 在一段时间内遵循不同动态先验，且系统接受多种激励，长期观测可能提供额外区分信息。
这里的非单射是单时刻局部结论。EnKF 得到的 h、epsilon 后验分解来自时间先验、支持域和历史观测共同正则化。

备用 05 · 答辩追问

加速、公平性与验证边界

63.4 倍包含训练吗？

不包含。该数值比较在线候选动作规划，每回合 0.099 s 对 6.258 s。

空间分辨率相同吗？

不同。世界模型 41 节点，BDF 81 节点，所以结论限定为部署配置加速。

BDF 是独立实验吗？

属于交叉求解器数值验证。离散方法不同，但连续 PDE 和物性函数相同。

中心测温是否泄漏答案？

五点布局直接含中心热电偶，因此主重建证据采用无中心四点方案。

物理约束为何并非处处更准？

它改变优化目标。本文依据验证轨迹选择权重，优势集中在物理一致性和参数组合外推。

下一步最关键的实验？

用热电偶实测曲线校准边界、物性和传感器响应，并扩展到二维截面。
