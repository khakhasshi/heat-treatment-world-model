# 基线实验记录

## 实验 001：一维热方程解析解验证

运行日期：2026-09-03

### 配置

- 随机种子：42
- 网络：4 个隐藏层，每层 32 个神经元，激活函数为 `tanh`
- 优化器：Adam
- 学习率：0.001
- 训练轮数：2000
- 方程内部配点：2000
- 边界配点：200
- 初始配点：200
- PDE、边界和初始损失权重：均为 1

### 结果

- 最佳轮次：1980
- 最佳总损失：`1.4819e-4`
- 相对 L2 误差：`9.9449e-3`，约 0.994%
- 最大无量纲绝对误差：`9.3295e-3`
- 按 800°C 温差映射的全场 RMSE：约 2.026°C
- CPU 训练时间：约 6.22 秒

### 初步解释

PINN 已正确逼近解析温度场，说明控制方程自动微分、初始/边界约束和误差评价链路均可用。误差图显示较大误差主要出现在边界附近及早期时刻，这与初始条件和边界条件交汇处更难同时拟合有关。

第 2000 轮的总损失短暂回升到 `2.970e-3`。训练器因此恢复第 1980 轮的最低损失模型，而不是直接使用最后一轮参数。后续实验应进一步研究学习率衰减、损失权重与 Adam 后接 L-BFGS 是否能减小此类波动。

### 有效边界

这只是无量纲解析基准，不能直接声称已经模拟真实金属热处理。进入工程算例前仍需确定具体材料、工件形状与尺寸、初始温度、介质温度以及表面换热系数。
