# 科研行文润色记录

本次修订覆盖两版论文的中英文摘要、六章正文及复现附录。正文保持预测、辨识、状态估计与闭环控制的既有论证结构，实验配置、结果和图表沿用已完成的计算。

## 文字处理

- 将章首的步骤导读改为研究对象、输入输出及评价范围的直接描述。
- 将设问式研究问题改为明确的研究内容、比较对象和检验方法。
- 压缩人为转折、自我解释和重复总结，按实验条件、统计结果、适用范围组织句子。
- 将“先平均、再重采样”等过程描述改写为统计量和重采样单位的定义，保留计算顺序所表达的统计含义。
- 保留“先验”“预先固定”等技术用语，以及递归预测、传感器状态更新和历史后验的因果关系。
- 结论中的三项小标题改为“递归预测精度与计算效率”“等效边界表示及其可辨识条件”“观测条件与闭环控制性能”。阴性结果及证据限制保留在对应结论中。

边界时变性的表述经复核收紧为建模难度及估计误差的影响，避免将边界随时间变化本身等同于预测误差来源。
