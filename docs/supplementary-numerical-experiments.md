# 补充数值计算实验

> 本页记录2026年9月的补充实验。后续逻辑审查增加的公平边界输入、成功率统计单位、近表面闭环、完整计时与三维动作修正见[2026年10月补充报告](thesis-audit-followup-20261001.md)。历史结果保留，当前论文采用明确修正后的口径。

## 1. 等效边界参数的反事实辨识

固定表面温度 300°C 和当前炉温 700°C，以 `h=35 W/(m2 K)`、`epsilon=0.775` 为参考，构造 5 组具有相同 `H_eff=121.675 W/(m2 K)` 的参数组合。当前动作下，各组合的边界热流差为数值零。将候选炉温扩展到 400--950°C 后，参数组合之间的最大热流差为 12.026 kW/m2，按冻结表面半控制体热容换算的 1 s 显式局部温升增量差为 9.226°C；该诊断不包含内部导热积分与边界反馈，不是 BDF 求解后的实际温差。

该实验给出两个计算事实。已执行动作下，`H_eff` 足以表示瞬时边界热流。候选炉温改变后，辐射基函数随动作变化，当前 `H_eff` 无法单独决定反事实热流，因此控制阶段仍需保留 `h` 和 `epsilon` 的后验组合。

```bash
PYTHONPATH=src uv run --no-sync analyze-counterfactual-identifiability
```

## 2. 严格参数 OOD 控制扩展

在原 10 条场景之外选取 40 条新场景，每个参数类别 8 条。新旧场景索引无交集。每条场景分别使用训练种子 42、7 和 123 的模型运行后验均值控制与 90% 风险分位控制。统计时先在场景内平均三个模型种子，再做 100000 次场景 bootstrap。

| 样本 | 指标 | 后验均值 | 风险分位 | 配对差 | 95% bootstrap 区间 |
|---|---|---:|---:|---:|---:|
| 原 10 条 | 综合目标 | 21.376 | 19.638 | -1.737 | [-3.291, -0.226] |
| 新 40 条 | 综合目标 | 26.019 | 25.531 | -0.488 | [-2.802, 1.950] |
| 新 40 条 | 平均超温/°C | 0.641 | 0.585 | -0.056 | [-0.527, 0.418] |
| 新 40 条 | 中心误差/°C | 6.616 | 7.162 | 0.546 | [0.070, 1.029] |
| 合并 50 条 | 综合目标 | 25.090 | 24.353 | -0.738 | [-2.630, 1.248] |

新 40 条场景中，综合目标有 23 条改善、1 条不变、16 条增加。均值方向仍偏向风险分位控制，但区间跨越零。中心误差平均增加 0.546°C。扩展结果不支持风险控制稳定降低综合目标的结论，支持的结论是风险分位排序能够改变约束与跟踪之间的权衡，其收益依赖具体场景。

```bash
PYTHONPATH=src uv run --no-sync evaluate-ood-partial-observability \
  --output-dir outputs/c45_ood_control_expanded \
  --scenarios-per-category 8 \
  --exclude-scenario-indices 15 13 0 16 1 8 5 20 11 3 \
  --controllers sparse_certainty_equivalent sparse_risk_aware \
  --closed-loop-only
PYTHONPATH=src uv run --no-sync analyze-ood-control-extension
```

## 3. 三维模型多种子重复

三维补充实验在相同的 96 条 `17 x 13 x 9` 轨迹上增加训练种子 7 和 123，并与原种子 42 汇总。每个种子先在 `9 x 7 x 5` 基础网格训练，再将形状相容的卷积权重迁移到加密网格。各模型独立依据验证集 300 步 rollout RMSE 选择检查点。

| 数据划分 | 数据模型 RMSE/°C | 物理模型 RMSE/°C | 数据模型残差/°C | 物理模型残差/°C |
|---|---:|---:|---:|---:|
| 验证集 | 3.922 +/- 0.698 | 3.990 +/- 0.359 | 4.863 +/- 0.150 | 3.402 +/- 0.152 |
| ID 测试 | 3.695 +/- 0.594 | 3.804 +/- 0.276 | 4.836 +/- 0.228 | 3.348 +/- 0.242 |
| 控制 OOD | 16.588 +/- 5.062 | 15.877 +/- 3.233 | 6.992 +/- 0.523 | 5.766 +/- 0.418 |

物理约束使三个划分的离散能量残差分别降低 30.0%、30.8% 和 17.5%。控制 OOD 的总体 RMSE 均值降低 4.3%。逐轨迹配对差为 -0.492°C，95% bootstrap 区间为 [-1.079, 0.023]°C，16 条轨迹中 11 条改善。区间仍跨越零，所以三维稳定结论限定为能量一致性；OOD 精度变化作为均值趋势报告。

训练命令沿用 `docs/three-dimensional-world-model.md` 中的正式协议，并通过 `--dataset` 让不同训练种子共享同一冻结数据集。汇总命令为：

```bash
PYTHONPATH=src uv run --no-sync aggregate-three-dimensional-replicates
```

## 4. 稀疏测温噪声与响应滞后

鲁棒性实验采用无中心测点的近表面四点布局。90 条独立 BDF 轨迹和三个模型种子共形成每个条件 270 条滤波记录。噪声实验同步修改观测噪声和滤波器观测协方差，其余参数沿用原校准值。滞后实验使用一阶传感器响应，滤波器仍按瞬时测量更新，因此衡量未建模响应动力学的影响。

| 条件 | 未测节点 RMSE/°C | 中心 RMSE/°C | 未测节点 90% 覆盖率 |
|---|---:|---:|---:|
| 噪声 0.2°C | 2.297 | 2.985 | 73.9% |
| 噪声 0.5°C | 2.128 | 2.854 | 81.5% |
| 噪声 1.0°C | 2.100 | 2.853 | 86.0% |
| 响应时间常数 2 s，噪声 0.5°C | 2.691 | 3.433 | 65.2% |
| 响应时间常数 5 s，噪声 0.5°C | 4.894 | 5.501 | 34.4% |

随机噪声在 0.2--1.0°C 范围内没有造成明显的 RMSE 恶化。较大的观测协方差降低了滤波器对局部测量的权重，覆盖率随之升高。响应滞后产生更清晰的退化，5 s 时间常数使未测节点 RMSE 增加到 4.894°C。部署时需要标定传感器动态，或将响应状态并入估计器。

```bash
PYTHONPATH=src uv run --no-sync evaluate-sensor-robustness
```
