# 温度场 World Model 架构

## 1. 状态转移

将一维工件离散为 `N` 个节点：

```text
s_t = [T_1(t), T_2(t), ..., T_N(t)]
a_t = T_infinity(t + dt)
p   = [h, epsilon, s_k, rho, s_cp, L, dt]
```

World Model 学习：

```text
delta_T = f_theta(s_t, a_t, p)
s_hat_(t+dt) = s_t + delta_T
```

预测温度增量而不是直接预测绝对温度，有利于保留状态连续性。

训练采用闭环多步展开：从真实状态出发后，后续各步均使用模型自己的上一时刻预测作为输入。这样可以直接惩罚误差累积，并使训练方式与最终递归推演方式一致。

## 2. 第一版网络

第一版使用小型残差多层感知机或一维卷积网络。当前网格较小，不立即引入潜空间编码器；只有当扩展到二维高分辨率温度场时，才考虑自动编码器、FNO 或 DeepONet。

## 3. 损失函数

```text
L_total = L_data + lambda_physics*L_balance
```

- `L_data`：预测下一时刻温度场与数值真值之间的均方误差。
- `L_balance`：内部节点采用温变物性的离散导热平衡，表面节点同时包含对流和辐射换热；残差按训练集温度增量尺度归一化。

物理范围不作为当前训练损失，而作为独立评价指标：预测下一状态若超出“当前整个温度场与环境温度共同确定的上下界”，记为最大值原理违反。不能用每个节点自身的前一时刻温度作为局部界限，因为邻近高温节点的导热可能使其合法越过该局部范围。

## 4. 数据划分原则

以整条工艺轨迹为最小划分单位。训练集、验证集和测试集分别包含不同的炉温曲线及换热系数组合。不能随机打散所有相邻状态转移后再划分，否则同一轨迹的近重复状态会同时出现在训练和测试中。

## 5. World Model 成立的判据

模型必须满足以下三点，才能在论文中合理称为 World Model：

1. 学习环境状态随时间的转移规律；
2. 转移显式依赖可改变的工艺控制量；
3. 能通过递归调用评估不同控制序列产生的未来温度场。

如果模型只能拟合一个固定工况的 `T(x,t)`，则仍属于 PINN 或代理求解器，而不是本课题定义下的 World Model。
