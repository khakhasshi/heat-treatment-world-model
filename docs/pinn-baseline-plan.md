# PINN 基线原始研究方案

> 本文档保留主题切换前的研究设计，作为 PINN 对照实验的依据。当前主课题与正式路线见 `world-model-plan.md`。

## 1. 题目

基于物理信息神经网络的金属热处理温度场数值模拟研究

## 2. 研究定位

本课题研究金属工件在加热或冷却过程中的瞬态温度场。重点不是证明 PINN 全面优于有限差分或有限元，而是考察：在控制方程和边界条件已知时，PINN 能否得到可信的连续温度场；在温度数据稀少时，能否进一步识别热物性或换热参数。

首阶段采用无物理实验路线。解析解、有限差分解或公开物性数据均属于数值研究资料，可以支撑本科论文的建模、对照和误差分析。

## 3. 核心问题

1. 如何把瞬态热传导方程、初始条件和边界条件写入 PINN 损失函数？
2. PINN 对温度场的预测精度如何，误差主要分布在哪里？
3. 配点数量、网络深度、学习率和损失权重如何影响收敛？
4. 少量温度观测是否能支持热扩散率或换热系数的反演？

## 4. 技术路线

### 阶段 A：解析基准问题

- 方程：一维瞬态热传导方程。
- 条件：定温边界和正弦初始温度分布。
- 目的：利用解析解检查 PINN 实现。
- 指标：相对 L2 误差、最大绝对误差、温度 RMSE、训练时间。

### 阶段 B：热处理工程问题

- 几何：优先选择厚度方向的一维平板；有余力再做轴对称圆柱。
- 边界：炉气加热或淬火介质冷却对应的第三类边界条件。
- 物性：先取常数，再研究导热系数和比热随温度变化的情况。
- 对照：有限差分法或有限元软件结果。

### 阶段 C：参数反演

- 给定少量内部测温点的温度-时间数据。
- 将热扩散率 `alpha` 或表面换热系数 `h` 设为可训练参数。
- 比较不同噪声、测点数量和测点位置下的识别误差。

## 5. 建议变量设计

控制变量：

- 网络层数和每层神经元数；
- 内部、边界和初始配点数量；
- 各损失项权重；
- Adam 训练轮数及是否增加 L-BFGS；
- 温度观测点数量与噪声水平。

结果变量：

- 温度场相对 L2 误差；
- 最大温度误差和 RMSE；
- PDE 残差；
- 收敛速度和计算时间；
- 参数反演相对误差。

## 6. 预期创新点

本科论文不必追求全新网络结构。更可靠的创新表述是：

- 将 PINN 应用于具体金属热处理边界条件，而非停留在一般热方程；
- 系统分析配点和损失权重对温度场精度的影响；
- 在正问题基础上完成热扩散率或换热系数反演；
- 对比 PINN 与传统数值方法在连续场表达和稀疏数据融合方面的特点。

## 7. 论文章节建议

1. 绪论：热处理温度场、传统数值方法和 PINN 研究现状。
2. 理论基础：热传导模型、神经网络、自动微分和 PINN。
3. 模型与实现：问题定义、网络结构、损失函数和训练方法。
4. 基准验证：解析解对照与超参数研究。
5. 热处理算例：对流边界、参数分析及传统方法对照。
6. 参数反演：稀疏测温数据下的参数识别，可作为提高章节。
7. 结论与展望。

## 8. 风险与降级方案

- PINN 收敛不稳定：输入归一化、增加初始/边界损失权重，或采用 Adam 后接 L-BFGS。
- 单轮损失偶发反弹：训练期间保存并恢复总损失最低的模型，同时报告最佳轮次。
- 二维模型训练过慢：论文主体保持一维平板，二维只作为扩展。
- 缺少实验条件：使用解析解、网格收敛后的有限差分解和文献物性数据。
- 逆问题效果不稳定：将参数反演作为提高内容，正问题与系统对照仍构成完整论文。
