# World Model 阶段实验结果

## 1. 实验设置

- 数值对象：厚度 20 mm 的一维钢制平板，41 个空间节点。
- 边界条件：两侧采用相同的对流换热边界。
- 数据集：100 条轨迹，每条 300 个状态转移。
- 数据划分：70 条训练、15 条验证、15 条测试轨迹。
- 工况变化：初始温度、目标炉温、升温时间和换热系数。
- 网络：3 个隐藏层，每层 128 个神经元。
- 状态转移：预测温度增量，闭环展开 5 步训练。
- 模型选择：以验证集完整轨迹滚动 RMSE 最低的轮次为准。
- 物理模型权重：0.01。

## 2. 数据充足实验

使用全部 70 条训练轨迹，训练 100 轮。

| 指标 | 普通 World Model | 物理约束 World Model |
|---|---:|---:|
| 测试滚动 RMSE | 0.612°C | 0.702°C |
| 一步 RMSE | 0.0063°C | 0.0072°C |
| 最终状态 RMSE | 0.814°C | 0.940°C |
| 滚动物理残差 RMSE | 11.94°C | 15.02°C |
| 最大值原理违反比例 | 0.0417% | 0.1160% |

结论：当精确数值标签充足时，物理约束没有提高测试精度，当前权重下滚动 RMSE 反而增加约 14.8%。这说明有限差分生成的密集标签已经携带了充分的热传导规律，额外软约束可能增加优化难度。

## 3. 少数据实验

只使用 5 条训练轨迹，保持同一验证集和测试集，训练 300 轮。

| 指标 | 普通 World Model | 物理约束 World Model |
|---|---:|---:|
| 测试滚动 RMSE | 15.42°C | 10.84°C |
| 一步 RMSE | 0.1838°C | 0.1195°C |
| 最终状态 RMSE | 23.38°C | 18.50°C |
| 滚动物理残差 RMSE | 526.85°C | 136.02°C |
| 最大值原理违反比例 | 0.6206% | 1.0201% |

结论：少数据条件下，物理约束将测试滚动 RMSE 降低约 29.7%，将滚动物理残差降低约 74.2%。这支持把物理约束定位为数据稀缺情况下的正则化手段，而不是无条件提高性能的机制。

## 4. 多步训练消融

少数据、物理权重 0.01、只做一步训练时，测试滚动 RMSE 为 72.62°C。改为闭环展开 5 步训练后，在第 100 轮降至 21.09°C；继续训练到 300 轮后降至 10.84°C。

该结果说明，一步预测误差很小并不保证长期推演稳定。World Model 必须在训练时接触自身预测形成的状态分布，并按完整验证轨迹选择模型。

## 5. 速度边界

在同一 CPU 上推演 15 条、每条 300 步的测试轨迹：

- 有限差分法中位耗时：约 0.0081 秒；
- World Model 批量推演耗时：约 0.0111 秒；
- 当前一维小问题中，World Model 约慢 1.37 倍。

因此当前结果不支持“快速预测”这一标题表述。有限差分模型规模很小且线性，传统方法本身已经极快。速度优势需要在二维、更细网格、温变物性或大量工艺搜索场景中重新检验。

## 6. 当前有效结论

1. World Model 能够学习炉温控制下的温度场状态转移并进行 300 步递归推演。
2. 长期推演必须使用多步闭环训练和轨迹级验证，不能只优化一步误差。
3. 物理约束在 5 条训练轨迹的少数据场景中明显改善泛化与物理一致性。
4. 在 70 条精确数值轨迹下，普通模型更准确，物理约束没有普遍优势。
5. 一维线性问题不足以证明神经模型具有速度优势。

## 7. 工艺规划验证

在 868 条候选炉温曲线中，以“最终中心温度接近 400°C，同时减小最终截面温差”为目标：

- 有限差分最优方案：目标炉温 910°C，80 秒线性升温；
- 普通 World Model 选择了完全相同的方案，候选集规划遗憾值为 0；
- 物理约束 World Model 选择目标炉温 850°C、30 秒线性升温；
- 经有限差分复核，物理模型方案的最终中心温度为 399.75°C，截面温差为 3.97°C，规划遗憾值仅为 0.077。

该实验说明模型已能够通过递归推演支持控制序列比较，满足本课题对 World Model 的操作性定义。但候选空间目前只有线性升温和保温，尚不能等同于实际工艺优化。

## 8. C45 温变物性与辐射扩展

第二轮将数值环境升级为 C45/AISI 1045 类中碳钢平板：导热系数和比热随温度变化，两侧边界同时包含对流与灰体辐射。数据集共 120 条、每条 300 步、41 个节点，其中 70 条训练、15 条验证、15 条同分布测试和 20 条控制曲线分布外测试。训练/验证/同分布测试只包含线性升温保温与两段加热，OOD 测试只包含炉温阶跃和升温后冷却。

辐射敏感性算例表明，在 850°C 环境、发射率 0.75 时，辐射等效换热系数约为 81.62-146.85 `W/(m^2 K)`，高于设定的 25 `W/(m^2 K)` 对流系数。忽略辐射会使 300 秒后的中心温度从 475.59°C 降至 154.99°C，因此高温炉内加热不能继续沿用纯对流边界。

### 8.1 同分布与总体 OOD

| 指标 | 普通 World Model | 物理约束 World Model |
|---|---:|---:|
| 同分布滚动 RMSE | **2.538°C** | 2.656°C |
| 同分布物理残差 RMSE | 57.37°C | **27.24°C** |
| 同分布最大绝对误差 | 20.28°C | **17.70°C** |
| OOD 滚动 RMSE | 5.687°C | **5.571°C** |
| OOD 物理残差 RMSE | 128.22°C | **68.06°C** |
| OOD 最大绝对误差 | 57.47°C | **41.45°C** |
| OOD 最大值原理违反比例 | 0.0919% | **0.0488%** |

同分布上，普通模型的平均滚动误差低约 4.6%，但物理模型的残差低约 52.5%，最大误差低约 12.7%。总体 OOD 上，物理模型的滚动 RMSE 仅改善约 2.0%，但物理残差降低约 46.9%，最大误差降低约 27.9%。因此最稳妥的结论不是“物理约束全面提高精度”，而是它在未见控制模式下改善了物理一致性和尾部误差。

### 8.2 按 OOD 控制类型拆分

| 工况与指标 | 普通 World Model | 物理约束 World Model |
|---|---:|---:|
| 阶跃保温滚动 RMSE | **4.822°C** | 5.189°C |
| 阶跃保温最大误差 | 30.67°C | **15.86°C** |
| 升温后冷却滚动 RMSE | 6.781°C | **6.099°C** |
| 升温后冷却物理残差 RMSE | 189.03°C | **62.18°C** |
| 升温后冷却最大误差 | 57.47°C | **41.45°C** |

优势主要来自升温后冷却：物理约束使该类 OOD 的滚动 RMSE 降低约 10.1%、物理残差降低约 67.1%。阶跃保温上平均 RMSE 反而变差约 7.6%，但最大误差接近减半。这说明不同分布外模式不能只汇总成一个均值，论文应同时报告工况分组和尾部误差。

### 8.3 物理权重消融与重复实验

首先固定训练种子 42，扫描四个物理权重。每个模型都按自身验证集完整轨迹 RMSE 保存最优检查点。

| 物理权重 | 验证 RMSE | 同分布测试 RMSE | OOD RMSE | OOD 物理残差 | 冷却 OOD RMSE |
|---:|---:|---:|---:|---:|---:|
| 0 | 2.357°C | 2.538°C | 5.687°C | 128.22°C | 6.781°C |
| 0.001 | 2.300°C | **2.003°C** | **4.825°C** | 69.40°C | **5.089°C** |
| 0.01 | **2.120°C** | 2.656°C | 5.571°C | 68.06°C | 6.099°C |
| 0.1 | 2.725°C | 4.530°C | 10.400°C | **39.88°C** | 12.252°C |

单次运行中，按验证集应选择 `0.01`，不能因为 `0.001` 的测试误差更低而事后改选。`0.1` 虽继续降低物理残差，却显著损害预测精度，证明“残差最小”不等于“模型最好”。

为降低初始化偶然性，对 `0、0.001、0.01` 使用种子 `7、42、123` 重复训练。下表为三次最优检查点的均值与样本标准差。

| 物理权重 | 验证 RMSE | 同分布测试 RMSE | OOD RMSE | OOD 物理残差 | 冷却 OOD RMSE |
|---:|---:|---:|---:|---:|---:|
| 0 | 2.282 ± 0.109°C | 2.389 ± 0.139°C | 5.994 ± 0.430°C | 127.41 ± 7.36°C | 7.081 ± 0.623°C |
| 0.001 | **2.035 ± 0.244°C** | **2.103 ± 0.123°C** | **5.589 ± 0.789°C** | 70.35 ± 4.24°C | **6.364 ± 1.149°C** |
| 0.01 | 2.242 ± 0.109°C | 2.739 ± 0.107°C | 6.865 ± 1.202°C | **60.29 ± 10.42°C** | 8.677 ± 2.275°C |

按预先规定的验证均值，最终选择 `0.001`。相对无物理基线，它使同分布测试 RMSE 平均降低约 11.9%，OOD RMSE 降低约 6.8%，冷却 OOD RMSE 降低约 10.1%，OOD 物理残差降低约 44.8%。但 OOD 标准差从 0.430°C 增至 0.789°C，且仅有三个训练种子，因此这些结果属于稳健性增强后的探索证据，尚不能表述为统计显著性结论。

### 8.4 数据量与固定优化预算

数据量实验使用嵌套训练子集，固定物理权重为验证选择的 `0.001`。初次实验统一训练 120 轮，但方法审查发现不同数据量对应的每轮批次数不同，会把数据增益和优化步数混合。因此正式结果改为每个模型约 `4920` 次参数更新，并把验证检查次数统一为约 12 次。对应的训练轮数分别为 1640、820、410、205 和 120。

| 训练轨迹 | 普通模型测试 RMSE | 物理模型测试 RMSE | 普通模型 OOD RMSE | 物理模型 OOD RMSE | 普通/物理冷却 OOD RMSE |
|---:|---:|---:|---:|---:|---:|
| 5 | **38.265°C** | 39.201°C | 81.474°C | **72.242°C** | 71.489 / **63.910°C** |
| 10 | **15.233°C** | 16.870°C | 21.452°C | **20.670°C** | 23.401 / **22.405°C** |
| 20 | **10.237°C** | 11.010°C | 19.215°C | **18.475°C** | 21.796 / **19.246°C** |
| 40 | 3.746°C | **3.507°C** | 12.045°C | **11.180°C** | 15.809 / **14.900°C** |
| 70 | 2.538°C | **2.003°C** | 5.687°C | **4.825°C** | 6.781 / **5.089°C** |

数据覆盖是主导因素：普通模型从 5 条增加到 70 条时，同分布 RMSE 从 38.265°C 降至 2.538°C，OOD 从 81.474°C 降至 5.687°C。物理约束在所有数据量上都降低 OOD 误差和物理残差，但在 5、10、20 条时没有改善同分布平均误差；达到 40 条后才同时改善同分布与 OOD。说明在温变物性、辐射边界和多类控制共同存在时，离散物理残差不能替代基本的状态与参数覆盖。

该曲线目前只有种子 42，不能把 40 条解释为普适阈值。它支持的有限结论是：物理约束提高了当前采样设计下的 OOD 稳健性，但复杂问题的少数据学习仍首先受轨迹覆盖限制。

### 8.5 参数分布外泛化

保持炉温曲线为训练中出现的升温保温或两段加热，只将换热系数、发射率、导热系数尺度或比热尺度推到训练范围外。每个单因素类别 20 条轨迹，另有 20 条四参数组合越界轨迹；三个训练种子均使用相同的 100 条测试轨迹。

物理权重 `0.001` 在五类参数 OOD 上的平均滚动 RMSE 均低于普通模型：换热系数降低 12.6%，发射率降低 6.0%，导热系数降低 23.6%，比热降低 2.2%，四参数组合降低 29.5%。组合 OOD 的最大误差由 121.76°C 降至 61.69°C，物理残差由 614.78°C 降至 233.62°C。

收益并非逐种子、逐方向一致。导热系数与组合 OOD 在三个种子上都改善；其余单因素各有一个种子未改善。高比热方向平均 RMSE 反而增加约 7.5%。详细范围、方向拆分和限制见 `docs/parameter-ood-results.md`。

### 8.6 动态边界条件 OOD

本轮保持所有瞬时参数值处于训练范围内，只让换热系数和发射率在单条轨迹中随时间变化。测试包含换热系数平滑变化、换热系数阶跃、发射率增长、发射率阶跃和二者联合动态五类，共 100 条轨迹。训练数据没有任何逐轨迹时变参数，因此该实验检验的是时间结构 OOD，而非参数数值范围外推。

在每一步都向模型提供真实参数时，普通模型总体 RMSE 为 `4.795 ± 0.289°C`，物理模型为 `4.089 ± 0.162°C`，降低 14.7%，且三个种子均改善。总体物理残差降低 57.3%，95% 分位逐轨迹 RMSE 降低 13.0%，但中位 RMSE 从 1.239°C 增至 1.333°C。物理约束的收益仍主要来自尾部，而不是典型样本。

若整段推演只使用第一步参数，普通模型和物理模型总体 RMSE 分别升至 19.477°C 和 19.418°C；即使使用事后时间均值，也分别为 7.673°C 和 7.306°C。说明物理损失不能补偿缺失的动态边界输入，实际部署必须同时解决参数在线测量或辨识问题。实验设计、分组结果与最差轨迹分析见 `docs/dynamic-boundary-ood-results.md`。

### 8.7 动态边界可辨识性与观测器

边界方程审查表明，单个时刻的温度转移只依赖 `H_eff(t) = h(t) + epsilon(t) h_rad(t)`。当 `h(t)` 和 `epsilon(t)` 都允许逐时自由变化时，瞬时灵敏度矩阵秩为 1，二者不能由温度观测唯一拆分。因此本轮从两侧表面及相邻节点温度的离散能量平衡中反演单一等效换热系数，并用因果后向窗口抑制噪声。

无噪声单步反演的 `H_eff` RMSE 仅为 `0.002 W/(m²·K)`。加入 `0.1°C` 独立高斯测温噪声后，15 秒窗口取得最低 RMSE `9.785 W/(m²·K)`；`0.5°C` 噪声下，30 秒窗口最低 RMSE 为 `18.451 W/(m²·K)`；`1.0°C` 噪声下，30-60 秒形成约 `23.8 W/(m²·K)` 的平台。结果显示短窗口放大差分噪声，长窗口则产生动态滞后和负偏差。

物理等价参数测试将 `h` 平均改变 12.60 W/(m²·K)、发射率平均改变 0.169，同时保持 `H_eff` 最大差小于 `9.0e-6 W/(m²·K)`。物理模型的等价参数对预测分歧为 `0.0249 ± 0.0021°C`，比普通模型的 `0.0308 ± 0.0023°C` 低 19.0%，三个种子和五类动态工况均改善。详细推导、噪声窗口和限制见 `docs/boundary-observer-results.md`。

## 9. 指标修订说明

早期实现把每个节点下一步温度限制在“该节点当前温度与环境温度”之间，这忽略了邻近节点导热，物理含义不成立。现已改为离散抛物型方程的全局包络：下一状态应位于“当前整个温度场的最小/最大值与环境温度”形成的范围内。本文所有最大值原理违反比例均按修订指标重算。

## 10. 当前论文主结论

1. 五步闭环训练是长期稳定推演的关键，一步精度不能替代完整轨迹评价。
2. 物理约束的价值依赖数据量与测试分布：少数据常物性实验改善最明显，精确标签充足时未必提高平均误差。
3. 三种子验证均值选择的物理权重为 `0.001`；它平均降低同分布、OOD 和冷却 OOD 误差，但 OOD 方差仍较大。
4. 固定优化步数后，C45 数据量实验显示物理约束始终改善 OOD，但少于 40 条轨迹时没有改善同分布误差。
5. 参数 OOD 中，物理约束对导热系数和多参数组合外推最稳定；比热外推收益最弱且存在方向不对称。
6. 动态边界 OOD 中，物理约束降低总体和尾部误差，但参数在线可观测性比物理正则化更关键。
7. 对流与辐射的两个自由时变参数不能由当前温度观测逐时唯一拆分；应优先估计等效换热系数。
8. 当前所有真值仍来自数值模拟；尚无实验温度曲线，不能把结果解释为真实工艺精度。

## 11. 下一轮研究

- 将训练重复扩展至至少 5 个种子，并报告置信区间或配对效应量。
- 对数据量曲线增加训练种子重复，检验 40 条附近的转折是否稳定。
- 将 World Model 的边界输入重参数化为等效换热系数，并采用序贯正则化进行闭环估计。
- 引入热电偶实验数据或公开基准，对数值环境和 World Model 做两级验证。
