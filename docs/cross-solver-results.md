# 跨求解器与跨网格温度场验证

## 1. 研究目的

前几轮训练、验证和动态边界测试都使用同一个 41 节点半隐式有限体积求解器生成温度真值。即使训练轨迹和测试轨迹相互独立，World Model 仍可能主要学习该求解器的一步离散规律，而不是对连续传热动力学具有可迁移性的近似。

本轮不重新训练任何模型，而是保持炉温、初始温度、材料参数以及动态 `h/epsilon` 历史不变，使用另一条数值路线重新生成 100 条测试轨迹。研究问题是：

> 当测试真值不再来自训练数据的离散转移算子时，`H_eff` 重参数化的优势是否仍然存在？

## 2. 参考求解器

新参考端采用高分辨率方法线离散，并由 SciPy `solve_ivp` 的 BDF 方法求解连续时间常微分方程组。BDF 是适合刚性问题的隐式多步、1 至 5 阶变阶方法。[SciPy solve_ivp documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.solve_ivp.html)

| 项目 | 训练数据源求解器 | 本轮参考求解器 |
|---|---|---|
| 空间节点 | 41 | 81 |
| 时间推进 | 固定 1 s 后向欧拉 | 自适应变阶 BDF |
| 最大内部步长 | 1 s | 0.25 s |
| 温变物性 | 每个 1 s 转移起点冻结 | 连续时间右端随状态更新 |
| 辐射边界 | 当前温度线性化系数 | 直接计算非线性 `T^4` 热流 |
| 输出 | 41 节点 | 81 节点解投影至原 41 节点 |

两者使用相同的 C45 物性表、密度、几何和物理边界。因此这是一项跨时间离散、跨非线性处理和跨网格验证，而不是与真实实验或完全独立商业有限元软件的交叉验证。

## 3. 参考解收敛性

完整 100 条轨迹使用 81 节点、最大内部步长 0.25 秒计算。每个动态类别再抽取 2 条，共 10 条执行两项收敛审计：

| 收敛检查 | 平均温度场 RMSE | 最大单轨迹 RMSE | 最大绝对差上限 |
|---|---:|---:|---:|
| 81 节点对 161 节点 | 0.00248°C | 0.00746°C | 0.0196°C |
| 最大步长 0.25 s 对 0.125 s | 0.00425°C | 0.00846°C | 0.0294°C |

参考解的空间和时间离散误差比后续 World Model 误差低两个数量级，可以用于本轮比较。已有物理信息算子研究也强调，应区分固定离散上的拟合与网格加密意义下的算子收敛，并采用不同分辨率施加或验证物理约束。[Li et al., Physics-Informed Neural Operator](https://doi.org/10.48550/arXiv.2111.03794)

原 41 节点求解器与 BDF 参考温度场的总体 RMSE 为 `0.166°C`，终态 RMSE 为 `0.312°C`，最大绝对差为 `0.956°C`。这说明新旧数值真值并不相同，但仍描述同一物理过程。

## 4. 跨求解器预测结果

下表是相对 81 节点 BDF 参考解的 300 步全温度场 RMSE，均为三随机种子均值和样本标准差：

| 模型和边界输入 | `weight=0` | `weight=0.001` |
|---|---:|---:|
| 旧模型，真值动态 `h/epsilon` | 2.539 ± 0.018°C | 2.316 ± 0.092°C |
| 新模型，真值动态 `H_eff` | **1.491 ± 0.065°C** | **1.460 ± 0.078°C** |
| 新模型，无噪声因果观测器 | 1.519 ± 0.076°C | 1.502 ± 0.088°C |
| 新模型，0.5°C 噪声观测器 | 9.723 ± 0.062°C | 9.902 ± 0.111°C |

真值动态边界下，`H_eff` 模型相对旧双参数模型分别改善 `41.3%` 和 `36.9%`。6 个相同种子、相同物理权重的配对结果全部改善，说明上一轮的结构优势没有依赖原训练求解器的精确离散格式。

一步 RMSE 也从旧模型的 `0.0338/0.0327°C` 降至 `0.0255/0.0261°C`。因此改善不仅来自长序列中偶然的误差抵消，也存在于局部状态转移。

五类动态边界的三种子平均结果如下：

| 类别 | 旧模型 `weight=0.001` | `H_eff` 模型 `weight=0.001` |
|---|---:|---:|
| 换热系数平滑变化 | 1.748°C | **1.379°C** |
| 换热系数阶跃 | 1.721°C | **1.438°C** |
| 发射率渐变 | 2.591°C | **1.471°C** |
| 发射率阶跃 | 3.066°C | **1.582°C** |
| 二者组合变化 | 2.134°C | **1.420°C** |

五类全部改善，且发射率变化类别改善最大。这与可辨识性分析一致：旧模型最容易把辐射贡献错误地绑定到发射率特征本身，新表示则直接输入对温度转移真正有效的组合量。

## 5. 观测器对离散失配的鲁棒性

无噪声时，使用由原半隐式平衡推导的观测器处理 BDF 温度数据，因果 `H_eff` RMSE 为 `1.468 W/(m²·K)`，偏差仅 `-0.014 W/(m²·K)`。该误差主要仍来自一拍延迟和首步先验，没有出现明显的跨求解器系统偏差。

加入 0.5°C 温度噪声后：

- `H_eff` RMSE 为 `18.388 W/(m²·K)`；
- 95% 绝对误差为 `38.617 W/(m²·K)`；
- 边界裁剪比例为 `21.9%`；
- 数据模型温度场 rollout RMSE 为 `9.723°C`。

这些数值与上一轮同源求解器保持集的 `18.486 W/(m²·K)` 和 `9.839°C` 非常接近，说明当前观测器的主要瓶颈是温度差分噪声，而不是训练与参考求解器之间的离散差异。

## 6. 计算速度

在同一台本地 CPU 上：

- 81 节点 BDF 参考求解器平均每条 300 秒轨迹耗时 `0.526 s`；
- `H_eff` World Model 单条 300 步推演中位耗时 `0.00883 s`；
- 参考求解器与 World Model 的耗时比约为 `59.6`。

这个比值只代表当前 Python 实现、当前网格和单轨迹测试，不能直接外推到工业有限元软件或 GPU 批处理。但它验证了世界模型作为快速重复推演器的基本计算动机。

## 7. 可以形成的结论

本轮进一步支持以下观点：

> `H_eff` World Model 学到的不是原 41 节点后向欧拉更新的纯粹复制；在时间积分、非线性边界处理和空间分辨率均改变后，它仍能保持约 37% 至 41% 的结构优势，并能接入因果边界观测器。

这比“在同一个模拟器划分出的测试集上准确”更接近可迁移的快速热状态模型，但还不能证明真实工业有效。剩余关键边界包括：

1. 两个求解器仍共享同一一维对称传热方程和物性表；
2. World Model 固定在 41 节点，本身不具备任意网格输出能力；
3. 尚未测试二维几何、左右不对称边界、接触换热和相变潜热；
4. 尚未用独立 FEM 软件或真实测温数据验证；
5. 速度比较未包含模型训练和数据生成成本。

下一项最有价值的纯计算实验是加入控制任务：由世界模型实时选择炉温，在 BDF 参考环境中执行闭环，并与固定工艺、PID 和理想模型预测控制比较。这样才能从“快速预测器”推进到“能够依据内部状态做决策”的证据。
