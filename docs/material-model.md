# C45 温变物性与辐射边界模型

## 1. 材料对象与证据边界

本轮数值对象采用与 C45 相近牌号的 AISI 1045 中碳钢。代码中的高温物性取自公开论文所列 AISI 1045 数据，不能表述为对某一炉批 C45 材料的实测标定结果。真实工件的成分、组织状态、氧化层和表面粗糙度都会造成偏差。

一项针对 AISI 1045 的实验研究在 25-150°C 范围内同时反演了导热系数与体积热容，并给出：

```text
k(T) = -0.02228 T + 52.500                 W/(m K)
rho*cp(T) = (0.00210 T + 3.43253) * 10^6 J/(m^3 K)
```

这组实验关系只覆盖低温区，适合作为趋势交叉检查，不足以直接支撑 900°C 炉温模拟。因此当前环境使用另一篇公开研究列出的 0-1000°C 表格，并进行分段线性插值。

## 2. 当前物性表

密度固定为 `7870 kg/m^3`。

| 温度 (°C) | 0 | 200 | 400 | 600 | 800 | 1000 |
|---:|---:|---:|---:|---:|---:|---:|
| 比热 `cp` (J/(kg K)) | 510 | 600 | 725 | 900 | 562 | 600 |
| 导热系数 `k` (W/(m K)) | 45 | 41 | 36 | 32 | 27 | 23 |

数据集额外采样 `k` 与 `cp` 的 `0.95-1.05` 倍缩放系数，用于模拟物性不确定性。温度超出 0-1000°C 时目前采用端点截断；本轮生成状态最高约 760.10°C，没有触发高温外推。

## 3. 控制方程

一维平板内部采用无内热源瞬态导热方程：

```text
rho cp(T) dT/dt = d/dx [ k(T) dT/dx ]
```

两侧表面采用对流与灰体辐射共同作用：

```text
q_surface = h (T_env - T_s)
          + epsilon sigma [(T_env + 273.15)^4 - (T_s + 273.15)^4]
```

实现中将辐射项线性化为等效换热系数：

```text
h_rad = epsilon sigma (T_s,K + T_env,K)
                      (T_s,K^2 + T_env,K^2)
```

每个时间步以旧状态计算 `k(T)`、`cp(T)` 和 `h_rad`，再隐式求解新状态。这是半隐式有限体积/有限差分近似，World Model 的物理残差与该离散格式严格一致。

## 4. 参数范围

| 参数 | 本轮范围 |
|---|---:|
| 平板厚度 | 10-40 mm |
| 空间节点 | 41 |
| 时间步长 | 1 s |
| 对流换热系数 | 10-60 W/(m^2 K) |
| 表面发射率 | 0.65-0.90 |
| 初始温度 | 15-40°C |
| 炉温上限 | 950°C |

发射率范围是研究性采样范围，并非特定表面状态的测量结果。论文中应把它视为待实验标定参数。

在一个固定敏感性算例中（20 mm、`h=25 W/(m^2 K)`、`epsilon=0.75`、初温 25°C、环境 850°C），辐射等效换热系数从初始约 `81.62 W/(m^2 K)` 增至 300 秒时约 `146.85 W/(m^2 K)`，明显高于对流项。300 秒后，对流加辐射模型的中心温度为 475.59°C，而关闭辐射时只有 154.99°C。该结果只说明在当前参数下忽略辐射会造成数量级显著的模型偏差，不是实验验证。原始数字见 `outputs/c45_radiation_sensitivity.json`。

## 5. 尚未建模的物理

- 奥氏体化等相变潜热没有显式建模；物性表在 600-800°C 的比热变化只能部分等效反映该影响。
- 没有组织演化、相变动力学、热应力、变形和氧化层生长。
- 炉气与炉壁被等效为同一环境温度，未求解炉内三维辐射传递。
- 当前“真值”来自数值环境，不是实验温度；模型精度只能说明对该环境的逼近能力。
