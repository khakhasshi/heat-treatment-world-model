# World Model 研究方案

## 1. 新题目

基于物理约束世界模型的金属热处理温度场演化预测研究

## 2. 研究目标

构建一个以温度场为状态、以炉温或冷却介质温度为控制量的动力学模型，使其能够在不同热处理工况下预测下一时刻温度场，并稳定地进行长时间滚动推演。通过加入热传导方程和边界条件约束，提高模型的数据效率、物理一致性和未见工况泛化能力。

## 3. 核心研究问题

1. 数据驱动模型能否学习不同炉温曲线和换热条件下的温度场状态转移？
2. 热传导物理约束能否降低长时滚动误差和非物理预测？
3. 模型能否泛化到训练中未出现的完整热处理工艺曲线？
4. World Model 与有限差分法的计算效率如何随问题规模变化？

## 4. 技术路线

### 阶段 A：数值环境与数据集

- 建立带双面对流和表面辐射换热边界的一维 C45 钢平板模型。
- 采用温度相关导热系数与比热，并保留物性不确定性缩放参数。
- 使用隐式有限差分法生成不同炉温曲线、初始温度和换热系数下的轨迹。
- 按完整轨迹划分训练、验证和测试集，杜绝相邻时间步泄漏。

### 阶段 B：普通 World Model

- 输入当前温度场、下一步炉温、换热系数和材料参数。
- 网络预测下一时刻的温度变化量。
- 使用多步闭环监督误差训练，建立数据驱动基线。

### 阶段 C：物理约束 World Model

- 在监督损失中加入离散热传导残差。
- 将表面对流与辐射边界统一写入离散能量平衡残差。
- 比较不同物理损失权重对预测精度和滚动稳定性的影响。

### 阶段 D：多步推演与工艺探索

- 在完整未见炉温曲线上进行长时间滚动预测。
- 比较一步误差、滚动误差、最大温差误差和计算时间。
- 提高内容：搜索满足中心温度要求且温度均匀性较好的炉温曲线。

## 5. 主要对照实验

1. 有限差分法：数值真值和速度基准。
2. 原 PINN：固定工况连续温度场求解基准。
3. 普通 World Model：只有数据损失。
4. 物理约束 World Model：数据损失加物理损失。

## 6. 评价指标

- 一步预测 RMSE 和最大绝对误差；
- 完整轨迹滚动 RMSE；
- 工件中心温度和表面温度误差；
- 最大截面温差误差；
- 热传导方程残差和边界残差；
- 最大值原理违反比例；
- 单条轨迹推演时间及相对加速比。

## 7. 论文结构

1. 绪论：热处理温度场、数值模拟、PINN 与 World Model。
2. 理论基础：瞬态热传导、有限差分、神经动力学模型与物理约束。
3. 数值环境与数据集：工况采样、轨迹生成和数据划分。
4. 温度场 World Model：状态、动作、网络结构和训练方法。
5. 结果分析：基线、消融实验、长时滚动和泛化测试。
6. 工艺推演案例：不同加热曲线下的温度均匀性分析。
7. 结论与展望。

## 8. 课题边界

本科阶段研究一维平板、C45 温变物性和对流加辐射边界。二维几何、相变潜热、组织演化、真实热电偶标定与闭环强化学习均作为展望，不同时纳入主体，以保证课题能够完整落地。
