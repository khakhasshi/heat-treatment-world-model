# BDF 工件中的闭环温度控制研究

## 1. 研究问题

前一轮证明了物理约束 World Model 可以跨求解器预测 300 秒温度场。本轮进一步检验：

> World Model 是否能在独立 BDF 工件中支持受约束的滚动炉温决策，以及只由历史温度辨识出的 `H_eff` 是否足以评价未执行动作？

已有工作已经提出用物理信息模型快速评价烘箱边界条件并构成传感反馈回路，也有研究把物理信息 RNN 或神经算子嵌入 PDE 约束控制。本轮把这条路线具体化到 C45 金属热处理，并额外考察动态对流、动态发射率和反事实边界可辨识性。[Zobeiry and Humfeld, 2020](https://arxiv.org/abs/2010.02011)；[de Giuli et al., 2023](https://arxiv.org/abs/2310.13937)；[Hwang et al., 2022](https://doi.org/10.1609/aaai.v36i4.20373)

## 2. 闭环任务

| 项目 | 设置 |
|---|---|
| 工件 | 81 节点、自适应 BDF、非线性辐射边界 |
| 场景 | 动态边界 OOD 保持集，每类 2 条，共 10 条 |
| 控制时长 | 300 s |
| 决策周期 | 20 s，共 15 次 |
| 目标 | 终态中心温度 350°C |
| 炉温候选 | 300、400、500、600、700、800、900、950°C |
| 约束 | 表面温度不超过 550°C |
| 代价 | 中心误差、终态不均匀度、超温、能耗和命令总变差 |

每次决策将一个候选炉温保持到剩余时域末端进行预测，只执行前 20 秒后重新规划。这是具有 move blocking 的离散 shooting MPC，不是对完整 15 维动作序列的全局优化。

共执行 280 个 BDF 闭环回合：40 个基线回合，加上 3 个训练种子、2 个物理权重、4 种 World Model 部署方式和 10 个场景的 240 个模型回合。

## 3. 对照控制器

1. `fixed_750c`：全程固定炉温。
2. `proportional_feedback`：根据当前中心温差选择最近的离散炉温。
3. `source_solver_mpc`：训练数据的 41 节点半隐式求解器负责规划，BDF 负责执行。
4. `reference_solver_mpc`：81 节点 BDF 动力学负责规划和执行，未来边界参数已知。
5. `legacy_world_model_oracle`：旧 `h/epsilon` 输入模型，未来参数已知。
6. `effective_world_model_oracle`：`H_eff` 模型，使用真实未来 `h/epsilon` 为每个候选炉温重新计算 `H_eff`。
7. `effective_world_model_observer`：只用过去温度变化估计当前 `H_eff`，以名义发射率分解后评价候选炉温；分别测试 0°C 和 0.5°C 边界传感噪声。

这里的 oracle 表示边界参数已知，不表示找到了全局最优控制。所有方法使用相同的有限候选动作和相同的滚动搜索规则。

## 4. 闭环结果

下表采用 `physics_weight=0.001`。`±` 后是 10 个场景之间的样本标准差；括号内是 3 个训练种子均值之间的样本标准差。

| 控制器 | 终点中心绝对误差 | 终态不均匀度 | 验证代价 | 成功率 | 每回合规划时间 |
|---|---:|---:|---:|---:|---:|
| 固定 750°C | 127.628 ± 90.162°C | 7.201°C | 192.645 | 10.0% | 0.000005 s |
| 比例反馈 | 66.116 ± 40.696°C | 2.235°C | 78.171 | 0.0% | 0.000054 s |
| 源求解器 MPC | 1.843 ± 1.118°C | 8.142°C | 17.637 | 100% | 0.652 s |
| BDF 动力学 MPC | 2.120 ± 1.098°C | 7.440°C | 17.635 | 100% | 6.258 s |
| 旧 World Model oracle | 2.091 ± 0.787°C (0.181) | 7.576°C | 17.042 | 100% | 0.080 s |
| `H_eff` World Model oracle | 2.096 ± 0.760°C (0.202) | 7.223°C | 16.260 | 100% | 0.099 s |
| `H_eff` 观测器，0°C 噪声 | **1.263 ± 0.636°C (0.025)** | 6.798°C | **13.599** | 100% | 0.098 s |
| `H_eff` 观测器，0.5°C 噪声 | 3.906 ± 2.555°C (0.827) | **6.294°C** | 16.952 | 93.3% | 0.098 s |

除固定 750°C 外，其余控制器都没有超过 550°C 表面温度约束。简单比例反馈过早降低炉温，受中心温度大滞后影响，300 秒时尚未接近目标。

相对 BDF 动力学 MPC：

- 源求解器 MPC 的动作一致率为 90.0%，规划加速 9.60 倍；
- 旧 World Model oracle 的动作一致率为 78.9%，规划加速 78.34 倍；
- `H_eff` World Model oracle 的动作一致率为 78.4%，规划加速 63.44 倍；
- 无噪声 `H_eff` 观测器动作一致率为 68.2%，规划加速 64.00 倍；
- 0.5°C 噪声观测器动作一致率为 57.8%，规划加速 64.02 倍。

World Model 并不需要复制每一个 BDF 动作才取得接近的终态。无噪声观测器的验证代价甚至低于 BDF 动力学 MPC，但不能据此声称它优于精确模型：当前滚动控制每次只比较“保持一个炉温至终点”的候选，不是全局最优序列搜索，模型偏差和离散动作也可能产生有利的误差抵消。

## 5. 反事实边界诊断

`H_eff = h + epsilon * B(T_surface, T_furnace)` 能唯一描述当前炉温下的总边界换热，但改变炉温会改变辐射基函数 `B`。因此，仅知道当前 `H_eff` 并不能唯一推出另一个候选炉温下的 `H_eff`；控制器仍需要对 `h` 和 `epsilon` 作结构假设。

| 观测条件 | 候选动作 `H_eff` RMSE | 已选动作 `H_eff` 绝对误差 | 终点误差 | 成功率 |
|---|---:|---:|---:|---:|
| 0°C 噪声 | 4.272 W/(m²·K) | 1.717 W/(m²·K) | 1.263°C | 100% |
| 0.5°C 噪声 | 13.833 W/(m²·K) | 13.117 W/(m²·K) | 3.906°C | 93.3% |

0.5°C 噪声下的 2 次失败都来自同一条平滑对流变化场景，终点误差为 10.53°C；第三个训练种子在该场景成功。五类边界中，噪声版本平均误差最高的是发射率渐变类 5.35°C，而唯一出现失败的是平滑对流类。这说明当前样本还不足以按类别作强排序，但已能定位主要失效链：温度差分噪声 -> `H_eff` 估计误差 -> 反事实动作排序变化 -> 闭环终点退化。

## 6. 物理权重的作用

本轮没有发现 `weight=0.001` 对所有闭环设置一致占优。oracle 情况下 `weight=0` 的终点误差略低；无噪声观测器中 `weight=0.001` 将三种子误差标准差从 0.260°C 降到 0.025°C；0.5°C 噪声下则是 `weight=0` 略好。

因此可写成：小物理权重改善了部分设置的训练稳定性，但当前证据不支持“物理损失普遍提高闭环性能”。结构化边界输入和观测质量的影响明显更大。

## 7. 当前结论

本轮支持一个收敛且有边界的判断：

> 在当前一维 C45 计算环境中，物理约束 World Model 已经是有用的快速闭环预测模型。它在独立 BDF 工件中以约 63 至 78 倍于 BDF 规划的速度，实现约 2°C 的 oracle 终点误差和 100% 成功率；但部署瓶颈不是神经网络推演速度，而是边界状态的可观测性和反事实参数化。

这也修正了更激进的说法：世界模型不是替代传热物理，而是把昂贵的重复 PDE 求解压缩成可用于在线候选搜索的状态转移器。`H_eff` 是预测充分的边界表示，但未必是控制充分的状态；要评价新炉温，还需辨识发射率、引入边界参数后验，或直接学习动作条件下的边界响应。

相关研究已经证明神经代理可用于 PDE 约束优化，并在钢材加热、连续退火等问题中探索快速温度预测和换热系数反演。[hot-rolled steel PINN](https://doi.org/10.1016/j.jer.2024.02.011)；[continuous annealing PINN](https://doi.org/10.1016/j.engappai.2023.107307)。本项目的新增证据是：把动态边界 OOD、跨求解器验证、因果观测器和闭环动作执行放进了同一条可复现实验链。

## 8. 研究边界与下一步

1. 仍是纯计算实验，BDF 工件和训练求解器共享一维对称传热方程与同一物性表。
2. 控制器直接获得无噪声 41 节点完整温度场；噪声只施加在边界观测器的 4 个节点上，因此不是完整的稀疏传感部署测试。
3. oracle 控制器知道未来 `h/epsilon` 历史，现实中只能预测或估计。
4. 每类只有 2 个场景，93.3% 成功率不能当作工业可靠性概率。
5. 当前动作搜索是单块保持的离散 shooting，不是多块序列优化、鲁棒 MPC 或概率约束控制。
6. 尚未覆盖二维几何、左右不对称换热、相变、组织演化和真实执行器动态。

下一轮最有价值的纯计算实验应是“部分可观测鲁棒控制”：只给表面和少量内部测点，同时估计完整温度场与边界参数后验；随后在参数集合上做 min-max 或 chance-constrained MPC。它能直接检验当前 0.5°C 噪声瓶颈能否被不确定性建模化解。
